## Auth Model

- **Middleware**: NextAuth `withAuth` wrapper protects all routes except `/login`, `/api/auth/*`, `/api/cron/*`, `/api/debug-env`, `/api/health/*`, `/api/integrations/office365/callback`
- **API Routes**: Use `getAuthContext()` from `@/lib/authServer` (wraps NextAuth session + admin checks)
- **Cron Routes**: Use `verifyCronAuth()` from `@/lib/cronAuth` (CRON_SECRET or Vercel header)
- **Admin Routes**: Additional `isAdminSession()` check (ADMIN_USER_IDS / ADMIN_EMAILS env vars)
- **Client**: NextAuth `SessionProvider` wraps the app in root layout

## Data Flow

```
Browser → Middleware (NextAuth JWT check)
  → Page Component (client-side, uses useApiClient hook)
    → /api/* route (getAuthContext → Supabase query → JSON response)
```

Components do NOT query Supabase directly. All data flows through API routes.
